# Third-party software

Project Zero depends on third-party Go modules, npm packages, Apple SDKs, and ESP-IDF components. Dependency versions and sources are recorded in the Go and npm lockfiles and the ESP-IDF component lockfile. Those components are distributed under their own licenses; the repository's MIT License does not replace them. Review each dependency's license and notices before redistributing a binary. GitHub dependency graph and Dependabot can identify updates for the checked-in dependency manifests.
