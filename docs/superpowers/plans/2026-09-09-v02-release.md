## Approved design
One release manifest supplies 0.2.0, build identity, protocol compatibility and migration level. Install ~/Applications/Zero.app with bundled daemon/CLI/observer; production data is ~/Library/Application Support/ProjectZero. One production LaunchAgent, explicit isolated development profiles, no fallback databases. Preserve history, grants, identities and pairing. Stable signing and permission retention must be tested. Provide version, doctor, dry-run installation/upgrade/rollback and bounded diagnostics.

Codex requires supported desktop-owned turn outcomes, not inferred success. Spend at most 60 active minutes probing attachment; no resume, replacement coding task, scraping, or inactivity inference. If unavailable, record exact blocker and continue independent work. Hooks are supporting evidence only.

Complete validated/scoped APIs and CLI, schema conformance, context revisions, durable sessions, Spotify, reminders, notification uncertainty and native controls. Optional parsing requires per-request export approval, Codex-owned authentication, enforced absence of tools/context, schema validation and proposal review. Defaults: one concurrent request, 30 seconds, 20/day, no retry or automatic calls. If restrictions cannot be enforced, keep parser disabled with evidence.

Stop obsolete soak collection and preserve incomplete evidence. No 24-hour or 14-day acceptance gate, no scheduled AI checks. Back up production consistently, retain rollback binaries/config/database, stop development services at cutover, migrate production only. Flash app region preserving device keys/config; verify hybrid view, BOOT, connectivity and version agreement.
