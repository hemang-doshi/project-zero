# Changelog

Project Zero's runtime, protocol and application versions are separate. Runtime values come from `core/release/manifest.json`; the Electron package version comes from `apps/desktop/package.json`.

## 0.2.0 — source snapshot

- Publishes the current local-first runtime, CLI, Electron desktop client, native macOS clients and ESP32 desk-node source as a curated snapshot.
- Runtime manifest build: `0.2.0-8`; wire protocol: `0.1`; render schemas: `0.1`, `0.2`; database version: `2`.
- Electron package version: `1.0.0`.
- This release contains source code only. It does not include signed/notarized installers or claim universal physical-hardware acceptance.
